# my codes

when viewing a demo page on my site, press Ctrl+U to view the source code then save it as an .html file.

for tutorials i\'ve written see the [site building tag](https://kwaamfan.neocities.org/notes/tags/site_building.html){target="_top"} of my notebook area.

all code here is shared under the [unlicense](https://unlicense.org/){target="_blank"}, except for the stardew valley theme which is shared under the [MIT license](https://opensource.org/license/MIT){target='_blank'} due to its derivation from an existing codepen. all i ask is if you learn anything at all from looking at my code, please consider being cool about people learning from looking at your own code too :)

i am not a web developer, just a self-taught hobbyist, so there\'s probably bugs and inefficiencies. if you have any issues or suggestions for improvements feel free to [contact me](contact.html) or send a pull request on the corresponding github repo.

+++ ## image gallery with popups and tag system
a responsive, mobile friendly image gallery. includes optional tag system for filtering images and popup boxes for each image. doesn\'t require javascript to function, although some is used to increase keyboard accessibility. designed to be used as a media log or review page. view a preview and instructions [here](/codes/gallery-with-tag-system/index.html){target="_top"}.

![image gallery with popups and tag system](images/gallery-with-tags.avif) {.img}
+++

+++ ## wii menu media gallery
a premade wii menu theme for sharing images. has a built in lightbox, which can display fullsize images, iframes, videos from youtube and other sources, and inline html elements when a channel is clicked. view a preview [here](/codes/wiimenu/index.html){target="_top"} and download [here](https://github.com/balfiere/wiimenu){target="_blank"}.

![an image gallery website layout based on the wii menu theme](images/wiimenupreview.png) {.img}

+++ ## draggable and collapsible windows
add windows to your site that you can collapse and expand on click, as well as drag from the title bar using the [draggabilly](https://draggabilly.desandro.com/){target="_blank"} javascript library.

view instructions and a demo using the styling i have on my site plus some other styles i made [here](/codes/mydraggabillydemo.html){target="_blank"}.

![](images/window%20preview.png) {.img}

### windows os css frameworks

if you use or are interested in using one of the windows operating system-like css frameworks [7.css](https://khang-nd.github.io/7.css/){target="_blank"}, [XP.css](https://botoxparty.github.io/XP.css/){target="_blank"}, or [98.css](https://jdan.github.io/98.css/){target="_blank"} on your website, check out this [code pen](https://codepen.io/balfiere/pen/PogdoWJ){target="_blank"} to see how to make windows draggable and collapsible. it has a css switcher so you can preview all three different frameworks. you can also view and download [this page](/codes/windowsOSdraggabillydemo.html){target="_blank"} on my site to see a demo using 98.css.
