## technology

### javascript libraries

the falling petals is from [Sakura.js](https://github.com/jhammann/sakura){target="_blank"}. the tooltips use [Tippy.js](https://atomiks.github.io/tippyjs/){target="_blank"}. the animations on the crafts page use [Rough Notation](https://roughnotation.com/){target="_blank"}. the scroll snapping and audio playback on the places page use GSAP\'s [ScrollTrigger](https://gsap.com/scroll/){target="_blank"}. the draggable boxes use [Draggabilly](https://draggabilly.desandro.com/){target="_blank"}, which i learned how to use by looking at [this codepen](https://codepen.io/maxakohler/pen/ZyEWgE){target="_blank"}.

### static site generators

the microblog was built using [microblog.py](https://notabug.org/likho/microblog.py){target="_blank"}. the notebook was built using [quartz](https://quartz.jzhao.xyz/){target="_blank"}. (almost) every other section was built using [eleventy](https://www.11ty.dev/){target="_blank"} using the liquid templating engine. i use the following plugins:

- [markdown-it-attr](https://www.npmjs.com/package/markdown-it-attrs){target='_blank'}
- [markdown-it-deflists](https://github.com/markdown-it/markdown-it-deflist){target='_blank'}
- [fs-extra](https://www.npmjs.com/package/fs-extra){target='_blank'}
- [gray-matter](https://www.npmjs.com/package/gray-matter){target='_blank'}
- [html-minifier-terser](https://www.npmjs.com/package/html-minifier-terser){target='_blank'} (and thanks to [petra pixel](https://petrapixel.neocities.org/coding/eleventy-tutorial#minify) for the code on how to use it)

### other

this site is written using [obsidian](https://obsidian.md/){target='_blank'}, [vscodium](https://vscodium.com/){target='_blank'}, and [neovim](https://neovim.io/){target='_blank'}. the code for my site, as well as the bash scripts i use to help manage everything, can be found on [my github](https://github.com/balfiere/neocities){target='_blank'}. the `public` folder is hosted on [neocities](https://neocities.org/){target='_blank'} using [deploy-to-neocities](https://github.com/bcomnes/deploy-to-neocities){target='_blank'}. if you want to know how i did something the unminified version of the html files are under the `eleventy/neocities` folder.

while i prioritize my own aesthetic preferences and artistic vision for my site, all attempts are made at making the site usable for mobile users and those who have javascript disabled. if you notice any bugs or have any accessibility concerns, feel free to [contact me](contact.html) or open an issue on the site's github.
