[Vita3k](https://vita3k.org/index.html){target='_blank'}
: vita emulator for windows, linux, mac, and android.

[Vita3k guide for Windows](https://www.reddit.com/r/VitaPiracy/comments/y0t0vx/how_to_play_psvita_games_on_pc_vita3k_guide_for/){target='_blank'}
: guide that walks you through how to start playing games on vita3k using the (decrypted) .zip install method. also shows you how to install a patch for use with vita3k using the diabolik lovers english patch as an example. another guide for playing and patching games for vita3k, using the (encrypted) .pkg method with the hakuoki ssl english translation as an example, can be found [here](https://stars-and-clouds.tumblr.com/post/706983563177951232/how-to-play-hakuoki-ssl-on-pc){target='_blank'}.

{% resourcesContainer "vita games" %}{% renderTemplate "md" %}

[NoPayStation](https://nopaystation.com/faq){target='_blank'}
: download vita games straight from the playstation server. a bit more complicated to set up than than just downloading from a rom site but safer and has a built in unpackager. follow the 'configuration and usage' section, following the areas that say 'PSV'. you can also download .pkg files straight from their site under the [browse](https://nopaystation.com/browse){target='_blank'} section, which also has zRIF codes/work.bin files (vita3k will ask you for one of these when you install a game through the .pkg method).
