[Eleventy](https://www.11ty.dev/){target='_blank'}
: i use eleventy to generate this site. i followed [this tutorial](https://whiona.weblog.lol/2023/10/my-neocities-workflow:-using-eleventy-and-the-cli-to-speed-up-development){target='_blank'} by [whiona](https://whiona.me/){target='_blank'} to learn how to set eleventy up but i use the following tutorial to update my site instead of Neocities CLI. special thanks to the [definition lists markdown-it plugin](https://github.com/markdown-it/markdown-it-deflist){target='_blank'} for making writing this site in markdown possible and making updates 100x easier.

[Deploy to Neocities](https://scumsuck.com/resources/deployneocities/){target='_blank'}
: tutorial on how to use github to update your neocities website. i highly recommend following this tutorial and coding your website in [VSCodium](https://vscodium.com/){target='_blank'} (basically visualstudio code without the microsoft telemetry). i found [this page](https://code.visualstudio.com/docs/sourcecontrol/intro-to-git){target='_blank'} to be very helpful in getting github connected to vscodium when i was having issues. also install the [live preview extension](https://open-vsx.org/extension/ms-vscode/live-server){target='_blank'} so you can live preview your code right as you're coding. special thanks to the [markdown all in one extension](https://github.com/yzhang-gh/vscode-markdown) for live rendering of the definition list syntax.

[Repth Themes](https://repth.neocities.org/theme){target='_blank'}
